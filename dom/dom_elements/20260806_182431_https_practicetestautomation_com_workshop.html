AI-powered test automation — a live workshop

Live, hands-on, small cohort. Honest about where these tools fail.

AI writes test code fast. It also routinely produces tests that pass while asserting the wrong thing — a locator that matches nothing, an assertion that can't fail, a happy-path check dressed up as coverage. Green pipeline, zero signal.

​

This workshop is about directing and reviewing AI-generated tests in a real project: onboard the codebase, plan, generate, review. You leave with a repeatable workflow and a kit you can run against your own repo on Monday — not a demo.

​

For engineers who've used chat AI to generate test code but never driven an agentic tool through a real project. You know the framework; you want AI to be useful in it. Not for beginners.
